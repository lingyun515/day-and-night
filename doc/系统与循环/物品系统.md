# 物品系统

## 分类

物品可分为：

- 货币
- 道具
	- 火力（e.g. 各种各样的子弹、箭矢、手榴弹）
	- 补给（e.g. 回复生命值的药品、回复饱腹值的食物、回复口渴值的水瓶、短暂属性增益的注射剂）
<!-- - 装备 -->
- 材料（用于建造设施，升级角色，修复基地，<!-- 制作道具 -->）
- 杂物（用于丰富世界观）

## 属性

物品具有以下属性：

- ID
- 标签
- 名称
- 描述
- 品质
- 价值
- 重量
- 最大堆叠数量
<!-- - 合成配方 -->
<!-- - 分解配方 -->

其中火力和补给的品质与强度（数值与机制）正相关

道具具有以下属性：

- 使用范围
- 使用时间
- 使用冷却
- 效果（对使用者或者被使用者的 Buff 和 Debuff）
- 效果描述

火力具有以下属性：

- 口径
- 伤害
- 飞行速度
- 声音距离

## 获取途径

物品可从以下途径获取：

- 场景中的物品
- 场景中的容器中的物品
- 商店消耗货币购买的物品
- 完成任务直接获得的物品

当 PC 不在当前场景时，场景中除任务道具以外的物品与容器会定时刷新
