# 基地系统

基地是相对安全的（无塔防事件时）

基地功能型建筑多种多样，大部分功能为提供角色属性数值成长（角色属性系统）

基地周围可以建造防御型建筑（防御系统），抵御外敌（塔防系统）

角色在基地可以存储物品（物品系统），存储物品容量有限（防止仓鼠党，同时关联对局带什么和留什么，以及清理仓库的必要），不过可以通过升级来提升存储物品容量上限，当仓库装满，而玩家又不想丢弃物资时，唯一的出路就是售卖出去换取货币

角色在基地可以与友方 NPC 进行交易（交易系统）

<!-- 角色在基地可以向友方 NPC 接取与提交任务（任务系统） -->

角色在基地可以通过睡眠跳到选定的时间点（时间系统）

靶场用于测试武器强度以及手感（战斗系统），暂定进入区域游戏的时间系统暂停，游戏不暂停，无缝

总之基地重要功能是备战（战斗系统）
