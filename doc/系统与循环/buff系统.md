# Buff 系统

不包括直接伤害与血量的瞬时计算以及改动（虽然都是通过 UE 的 GE 实现）。
游戏没有复杂的被动  Buff  技能（如当角色获得任何增益  Buff  时，自身防御力提升 10%），成长系统只是单纯地根据角色选择的技能升级给予对应的属性数值提升，因此和 Buff 系统无关。与 Buff 系统紧密相连的是装备系统和物品系统。

## Buff 系统定义

在游戏底层中， Buff 和 Debuff 本质是一个附着在角色身上的逻辑容器，其包含了：

- 生命周期：什么时候开始，持续多久，怎么消失。（包括 UE 中 GE 的 instant 和 duration）
- 叠加规则：能不能叠加，上限几层，时间机制（有固定时间上限，并且每次获得一层则效果持续时间刷新至时间上限，时间一到整个 Buff 或 Debuff 消失，而不是每层独立计时，即一层一层掉）。
- 效果列表：效果具体对哪些属性做什么影响。

## Buff 组合

- 在游戏中，不同的 Buff 和 Debuff 可以在同一时间共同作用到角色身上，即玩家可视的简单易懂的状态（止血状态带来了瞬时的清除出血 Debuff 的 Buff 以及持续一段时间的出血免疫 Buff ）。
- 角色身上可以同时存在多个状态，即角色可以同时被多个 Buff 和 Debuff 影响。不同的 Buff 与 Debuff 之间有着不同的关系，例如一部分 Buff 和 Debuff 处于完全对立而无法共同附着于角色身上，一部分 Buff 和 Debuff 则是叠加或是抵扣相同影响属性的数值。
