# 战斗系统

## 死亡机制

PC 死亡 -> PC 的上一次死亡生成的遗物消失，并在本次死亡地点生成遗物 -> PC 在基地重生

NPC 死亡 -> 在本次死亡地点生成遗物

遗物是存放角色死亡之时拥有的道具栏、装备栏、以及背包中的物品的容器

## 攻击方式

角色在战斗中的直接攻击方式分为：

- 近战攻击
- 远程攻击（主要）
	- 射击
	- 投掷

## 战斗设计要素

### 战斗触发

- 主动触发，己方角色在视野内发现敌方角色后主动对其产生伤害
- 被动触发，敌方角色在视野内发现己方角色后主动对其产生伤害

### 目标选择

游戏中做了友方和敌对阵营的区分，角色仅会选择敌方阵营角色且大部分情况下仅能对敌方阵营角色造成伤害（手雷等投掷物产生的范围爆炸可以对友方阵营角色造成伤害等）。且除玩家之外的角色的目标选择无法自由更改，即角色完成战斗的目标选择后，在当前选择目标死亡或者脱离视野前无法再选择其他目标（经典卡劳登的仇恨后带到两只雇佣兵旁边驱狼吞虎）。

### 战斗指令

战斗指令分为：

- 基础指令
- 战术指令

两者的区别主要在：在战斗中的使用频率

#### 玩家战斗指令

##### 基础指令

- 攻击：无论是近战武器还是远程投射武器，都通过攻击键触发攻击指令造成伤害。
- 移动：角色通过四个方向移动键以及一个运动状态切换键触发移动指令规避伤害，移动距离根据角色的移动速度和移动时间计算。
- 瞄准：角色在战斗中通过瞄准键位以及鼠标光标移动触发瞄准指令改变面朝向以及子弹分布区域。

##### 战术指令

- 使用道具：角色在战斗中可以通过快捷栏键位触发使用道具指令辅助角色造成以及规避或阻挡更多不同的伤害。
- 翻滚躲避：角色在战斗中可以通过翻滚躲避键位触发翻滚躲避指令规避伤害，具体表现为角色在短时间内处于无敌状态并进行了一段距离的位移。
- 换弹：角色在战斗中使用枪械武器时可以通过换弹键位主动触发换弹指令，或者使用枪械当前可直接发射子弹数归零后由系统控制强制角色执行换弹指令，换弹后系统会自动扣减背包携带的枪械的备弹（同口径）的数量，角色当前枪械武器的可直接发射子弹数会增加。
- 切换武器：角色在战斗中可以通过切换武器键位触发切换武器指令而使用不同武器造成不同的伤害。
- 互动：角色在战斗中可以通过互动键位触发互动指令与环境进行互动，如打开房门等。

#### ai敌人战斗指令

ai敌人一切战斗指令皆通过ai控制器结合行为树，状态树触发，自动执行。

##### 基础指令

- 攻击：角色根据手中的武器对视野内非己方阵营的角色执行近战攻击或者远程投射攻击指令造成伤害。
- 移动：角色根据与选择目标之间的距离，目标所处位置，周围环境（作为掩体），自身以及敌方阵营角色数量的多少执行移动指令自动移动到合理位置规避或造成更多伤害。
- 瞄准：敌对阵营角色出现在角色视野范围内，角色自动执行瞄准指令改变面朝向以及子弹分布区域。

##### 战术指令

- 使用道具：角色根据自身当前属性，状态结合自己背包中所有的物品执行使用道具指令辅助角色承受更多伤害（仅停留在会使用药品恢复血量）。
- 翻滚躲避：部分特殊敌人（如各种boss）具有翻滚躲避的能力，会根据自己的位置和目标角色，以及其生成弹幕的位置自动执行翻滚躲避指令规避伤害或接近，远离目标角色，具体表现为角色在短时间内处于无敌状态并进行了一段距离的位移。
- 换弹：角色在战斗中使用枪械武器时，使用枪械当前可直接发射子弹数归零后由系统控制强制角色执行换弹指令，并且直接增加角色当前枪械武器的可直接发射子弹数，使角色可以继续无限地进行远程投射攻击，直至战斗结束。

### 伤害判定指令

#### 近战攻击

近战攻击指令：同阵营目标无伤害判定，敌对阵营目标根据双方装备，buff，属性计算受到伤害（追求优化，不做距离衰减判定指令）。

#### 远程投射攻击

枪械射击指令：同阵营目标关闭伤害通道，子弹无伤害；敌对阵营目标根据双方装备，buff，属性计算伤害，比近战攻击多一个判定距离衰减的指令。
爆炸投掷指令：不区分阵营，范围内所有单位都开启伤害判定（唯一无视阵营保护的指令）。

### 战斗空间

除了玩家安全屋，全地图都是可发生战斗的空间。
每次战斗所包含的空间基本等于（略大于）交战战斗单位的视野范围。
可战斗空间中的掩体可大致分为三个等级：第零级是平地，没有任何遮挡。第一级是低掩体，这类地形会阻挡角色的移动，可完全阻挡近战攻击造成的伤害，但所有远程投射攻击造成的伤害均无法被阻挡。第二级是可以完全阻挡所有近战攻击产生的伤害及阻挡部分远程投射攻击产生的伤害（无法阻挡范围伤害以及暴击伤害）的战术掩体，如矮箱和沙袋，同时，这类掩体具有生命值，会受所有攻击产生的伤害影响而被破坏，进而演变为平地。角色贴近沙袋会进入特殊状态：所有远程投射攻击可以穿过沙袋命中敌方。第三级是可以完全阻挡所有攻击造成伤害的地形掩体，如墙体，树木，车辆等。

### 战斗单位

游戏为单机，所以战斗单位仅包含玩家角色和ai敌人。

### 战斗移动

角色在战斗中的可选移动方式与探索时一致，即都可以朝任意方向以静步，行走，跑步，翻滚方式进行移动。
战斗持续期间，战斗空间会随着交战战斗单位的位置变化而移动。

### 战斗结束

- 战斗结束的条件：战斗空间中只剩下一个阵营的角色时，战斗即为结束。
- 战斗结束的处理：死亡角色会留下遗物，当玩家作为存活阵营的角色时，玩家可以通过搜刮遗物来获取装备，物品作为战斗奖励。当玩家作为死亡阵营的角色时，玩家大部分装备，物品（除近战武器，保险箱物品，图腾）存入遗物留在死亡所在地（高难度或者未捡回遗物后再次死亡则直接销毁玩家遗物）中，玩家需要回到地图的上次死亡所在地通过搜刮遗物来取回自己的装备，物品作为战斗惩罚。

## 战斗核心&设计

### 核心框架

以角色属性基底为核心属性，以装备养成为主要属性放大器和差异放大器，角色成长与道具使用为次要。

### 核心战斗底层

#### 基础战斗逻辑

##### 伤害计算公式

```txt
不暴击伤害 = 武器伤害 × 护甲减免 × (1 + 单元素伤害倍率 + 其他元素伤害倍率 + …) × 游戏难度伤害倍率
暴击伤害 = 武器伤害 *暴击倍率* 护甲减免 *( 1 + 单元素伤害倍率 + ... )* 游戏难度伤害倍率
伤害期望 = 武器伤害 ×[ (1 - 暴击率) + 暴击倍率 × 暴击率 ] × 护甲减免 × ( 1 + 单元素伤害倍率 + 其他元素伤害倍率 + … ) × 游戏难度伤害倍率
武器伤害 = 武器面板伤害 *子弹伤害系数* 角色成长伤害倍率 / 单次射击的子弹数
暴击倍率 = ( 武器暴击倍率 + 子弹暴击倍率 ) *( 1 + 角色成长暴击倍率 )
护甲减免 = 2 / ( 护甲 - 护甲穿透 + 2 )
单元素伤害倍率 = 元素伤害倍率* ( 目标元素伤害系数 + 天气元素伤害加成 )
近战暴击率 = 近战武器自身暴击率 × (1 + 角色近战暴击率加成)
```

枪械没有泛暴击率，玩家做出爆头操作（准星刚好在敌人头上）即判断为暴击
其中：
枪械具有距离衰减，超距离衰减系数为0.5。

暴击倍率在未暴击时为1；

护甲在暴击时为头部护甲，未暴击时为身体护甲；

护甲 - 护甲穿透 会被限制在0-999的范围内；

元素伤害倍率默认为1，目标元素伤害系数默认为1；

天气元素伤害加成，雨天火伤害为-0.15，电伤害为+0.2；

游戏难度伤害倍率见游戏难度。

##### 战斗信息反馈

游戏中的战斗信息反馈分为：音效，飘字，动画，特效，准星样式。

- 音效：
	- 武器音效：近战武器和各种远程投射武器的音效。
	- 伤害音效：暴击伤害和普通伤害命中的音效。
	- 道具音效：不同道具使用时的音效。
	- 行为音效：角色在执行战斗指令时的音效。
	- 状态音效：角色处于不同状态（正常，受击，死亡）时的音效。
- 飘字：
	- 伤害飘字：暴击伤害和普通伤害命中时的伤害值飘字（暴击：伤害值前多了个暴击标识符）。
	- 属性飘字：角色收到属性攻击时显示的伤害值飘字（物理白，毒绿，电蓝，火红，空间紫）。
	- 行为飘字：角色在进行战术指令时显示其飘字（特指ai敌人换弹时头上出现聊天框，内容为“换弹！”）
- 动画：
	- 行为动画：角色在执行战斗指令时的动画。
- 特效：
	- 状态特效：角色处于不同状态（正常，受击，死亡）时显示的特效。
	- buff特效：角色身上挂有特殊的时间持续型buff时显示的特效。
	- 攻击特效：不同武器的不同属性攻击显示的特效。
- 准星样式：
	- 伤害：普通伤害和暴击伤害命中时的准星样式。
	- 行为：角色在执行战斗指令时的准星样式（做花费时间的行为时准星中间出现蓝色倒计时圆环）。

##### 输入与操作响应逻辑

角色受到控制器控制，根据控制器输入执行战斗指令时，底层有一套响应逻辑。

- 动作打断逻辑：角色在执行部分战斗指令（换弹，用道具）时，可以通过翻滚战斗指令强制切断当前动作的所有收益和剩余前摇，即主动打断。游戏无被动打断。
- 动作：角色的动作只有准备阶段（前摇），生效点，无动作结束后的收招部分（后摇）。
- 指令队列：游戏所有动作无后摇，即无预输入需求。
- 动作融合：移动和瞄准可以和除翻滚外的所有指令融合执行。

### 玩家战斗核心逻辑

作为PVE游戏，玩家的战斗核心分为三部分：养成（角色的属性成长和装备升级），验证（击败每个地图的不同敌人，打出或承受不同属性的更高伤害值），目标建立（完成随游戏流程以及剧情推进派发的一系列任务，击杀每个地图的boss）。而每个阶段的战斗力分布，就是为玩家战斗核心预留的空间。
