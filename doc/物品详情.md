# 物品详情

物品具有以下属性：

- ID，uint
- 标签，tag[]
- 名称，string
- 描述，string
- 品质，enum
- 价值，uint
- 重量，double
- 最大堆叠数量，uint

道具属性：

- 效果，GameplayEffect（包括了对使用者或者被使用者的 Buff 和 Debuff）

- 口径，tag
- 伤害，uint
- 射程，double
- 子弹速度，uint
- 声音距离，double
