物品可分为：

- 货币
- 限次品
	- 火力（各种各样的弹药）
	- 消耗补给（e.g. 回复生命值的道具（药品）、短暂属性增益道具（注射器）、回复饱腹值的道具（食物）、回复口渴值的道具（水资源）、回复氧气的道具（氧气瓶））
<!-- - 装备 -->
- 任务道具
- 材料（用于建造设施，升级角色，修复基地，<!-- -制作限次品等 -->）
- 杂物（用于装饰和以物换钱）

物品详情：
具有以下通用属性：
- ID   int
- 标签  tag
- 名称  string
- 描述  string
- 品质  int
- 价值  int
- 重量  int
- 可堆叠数量  int
