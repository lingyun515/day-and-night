# 概述

代号：白天与黑夜，昼夜，day-and-night
类型：范式单机

- ACT（按什么键角色就做什么动作特性，游戏不仅考验角色等级和武器装备，还考验反应操作和博弈技术）
- RPG（扮演一个角色，在虚构大世界进行活动，经历完整故事（剧情细节是类魂的碎片化叙事），角色根据等级，装备不断变强）
- Tower Defense（注重布局和单线防御）
- Roguelite（具有单局游戏的结构，即穿好装备，选择地图，在里面活动的最终目的都是寻找撤离点。无 Rogue 的永久死亡惩罚，随机生成地图以及单向进程累计（单局基本上都是从零开始），而是放宽死亡严格性（正常难度可以捡回遗物，具有保险箱和藏身处元素），具有随机出生点，随机资源，随机敌人的随机刷新位置和行为，玩家需要根据局内因素动态做出选择，拥有局外的永久属性成长）
- Top Down（从上方观察，角色在下方）
- TPS（将物体投射出去作为主要攻击手段，存在视野机制，无法看到角色周围全局环境，不是对角色周围环境全知全能的上帝视角）
- PVE（强调单机玩家与 NPC 的战斗）
- Open World（将所有东西融合在一个广阔自由地图，分区间具有一定联系，可以去任何地方做“任何事”）
